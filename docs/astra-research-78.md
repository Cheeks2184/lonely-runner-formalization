# Pass 78: zero-contact restoration and a global strategy test

The closest-odd folding analysis has not produced a uniform reverse
transfer. This pass finishes the first-fold-zero investigation and tests
a different proposed global inequality before investing in formalization.
Unrestricted LRC remains unresolved; the canonical six-total-runner
theorem remains the established transition to arbitrary-count research.

Write `d=N-1` and `alpha=1/(d+1)`. If the largest deleted speed `z`
is active and its opposite contact has folded absolute value two, the
old optimum is `mu=b/[2(z+b)]`, with `b` divisible by four. A strict
minimal failure would require `(d-1)b/2<z<(d-1)b`. The original
quarter cell has exactly this pair ceiling, so it cannot supply the
target. An exact uniform good family separately shows that a canonical
witness for the smaller fold need not restore the deleted coordinates.

Translation to all common half-time centres gives an explicit alternative.
Writing the deleted gcd as `2g`, `b=4B`, and `h=g/gcd(g,B)`, the
case `h=1` blocks every such central cell. If `h>1`, explicit grid
times give the deleted coordinates and `b` simultaneous margin above
`1/3`. Their full phase orbits and strict bad-count formula preserve
the closed canonical boundary. They do not force a time good for every
remaining original speed. In particular, a retained speed `4g` can
block every central cell in a precisely stated conditional ratio band.
No hypothetical failure realizing that band has been constructed.

These restrictions identify where this approach stops. Further fold
calculations need a new global invariant that supplies a common original
witness or transports failure to a smaller tuple. The present restrictions
alone justify neither conclusion.

An independent strategy assessment proposes testing the global integral
`I(a)=integral_0^1 product_i (||v_i t||-a)_+ dt`. The proposed estimate
`(alpha-a)(-I'(a)) <= (d+1)I(a)` would imply all strict subcritical
witnesses, then the closed endpoint by compactness. Its local version
uses each actual phase cell's own maximum; replacing these different
maxima by `alpha` requires an unproved global compensation estimate.
This stronger inequality is a falsifiable proposal, not an established
theorem or a proof of LRC.

The intended formal caller is the existing
`conjecture_iff_positiveIntegerConjecture` in `BHKRealReduction.lean`.

positive integer speeds, with the closed threshold `1/(d+1)`. A primitive
integer result would first need gcd rescaling, and the one-moving-speed
case is separate. This route would supply that input directly; the
existing finite-family equivalences do not prove the new inequality.
