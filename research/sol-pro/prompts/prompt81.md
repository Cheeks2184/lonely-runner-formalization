## Frozen common pivot definitions and boundary

For `n>=1`, put `N=n+1` and let

```text
a : Fin n -> Nat
```

be positive and injective. For pivot `j`, put

```text
p_j = a_j,
M_j = N*p_j,
rho_M(x) = min(x mod M, M-(x mod M)),
R_j = {r in {0,...,M_j-1} : N does not divide r},
B_i^j = {r in R_j : rho_(M_j)(r*a_i) < p_j}  for i != j,
mu_j(r) = #{i != j : r in B_i^j},
Q_j = {r in R_j : mu_j(r)=0}.
```

Badness is strict `<p_j`; equality is safe. Retain both cyclic sides,
excluded `N`-multiples, nonunits, gcd degeneracies, repeated modular residues,
coincident bad sets, reflection fixed points, and separate owner labels.

For a covered pivot, a complete owner set `C` satisfies

```text
C subset {i : i != j}
and union_(i in C) B_i^j = R_j.
```

Inclusion-minimality gives nonempty owner-labelled private sets, but an owner
omitted from `C` may still cover such a point. Do not turn relative privacy
into global safety.
